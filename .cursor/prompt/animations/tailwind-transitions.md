# Como Usar Transições do Tailwind

Para animações simples (hover, focus), use classes de transição do Tailwind.

## Aplicação:

```tsx
<button className="transition-all duration-300 hover:scale-105 hover:bg-blue-600">
  Clique
</button>

<div className="transition-opacity duration-200 hover:opacity-50">
  Conteúdo
</div>
```

Classes: `transition-*`, `duration-*`, `ease-*`, `delay-*`
