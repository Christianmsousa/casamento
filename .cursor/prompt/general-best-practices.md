# Melhores Práticas Gerais

Sempre siga estas práticas:

- ✅ TypeScript obrigatório
- ✅ Server Components por padrão (`'use client'` apenas quando necessário)
- ✅ Tailwind primeiro (CSS custom só quando necessário)
- ✅ Variants (cva) para componentes com variantes
- ✅ `cn()` helper sempre para combinar classes
- ✅ Componentes pequenos (uma responsabilidade)
- ✅ Documente funções complexas (JSDoc)
- ✅ Consulte `project_structure.md` sempre
